# Governed Agent Participation Record

**Use boundary:** Illustrative field tool; not safety certification or proof of
production fitness

**Validation state:** `unrun`. Completing this record does not prove correct
reasoning, safe autonomy, prompt-injection immunity, complete provenance,
proper tool effects, or an acceptable business outcome.

Use this worksheet for an AI agent participating inside one durable workflow.
The agent is a participant, not the owner of the business promise or the source
of transition authority. Record authorized responsibility and human decisions
in the canonical Responsibility-and-Progress Brief and Human Approval-and-
Escalation Map. If the agent can create a partial, ambiguous, repeated,
compensating, or residual effect, route the same stable decision ID to the
Compensation-and-Failure Matrix. Plan challenges in the Time-and-Failure Test
Plan.
